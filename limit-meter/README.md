# limit-meter

利用上限の5時間枠と週の枠を、どれだけ使ったかとリセットの時刻とあわせて、入力欄の上に出すmodです。

```
上限  5時間 █████░░░ 62%（3:30リセット）  週 █░░░░░░░ 17%（10/6 23:00リセット）
```

## すること

| いつ | すること |
|---|---|
| 起動したときと、Claudeが答え終わるたび | 入力欄の上の表示を新しくする。70%から黄色、90%から赤 |
| 5時間枠が80%と95%を超えたとき、週の枠が90%を超えたとき | 右上に知らせを出す（同じ枠の同じ段階では1回だけ） |
| 5時間枠が90%以上、または週の枠が95%以上のとき | 頼みごとに一文を添えて、Claudeに伝える |

Claudeに添える一文は次のとおりです。画面には出ません。

> [limit-meter] 利用上限が近づいています（5時間枠は92%使用、3:30にリセット）。上限に達すると、作業は途中で止まります。この依頼で2つ以上のファイルを書き換えるなら、書き換える前に、区切り方を短く提案して、ユーザーの返事を待ってください。1つのファイルで済む作業なら、そのまま進めてかまいません。

Opus 5.5では、この一文を読んで区切り方を先に出しました。Haiku 4.5では、そのまま書き換えを始めました。モデルによって効き方が違います。

## 表示を試す

上限に近いときの見え方は、`LIMIT_METER_DEMO`に5時間枠と週の枠の割合を入れて起動すると確かめられます。リセットの時刻は本物のままです。

```
LIMIT_METER_DEMO=92,40 claude
```

## 気をつけること

- 数字が出るのは、Pro、Max、Teamなどのプランで使っているときだけです。APIキーで使っているときは、代わりにそのセッションの料金を出します
- modの中の時計はUTCで動きます。そのため、手元のタイムゾーンを`TZ`、`/etc/localtime`、`date +%z`の順に読み、リセットの時刻をその時刻で出します。どれも読めないときは、時刻のあとに「UTC」と付けます
- 数字は、Claudeの応答と一緒に届いたものです。Claudeが何も答えていない間は、表示は変わりません
